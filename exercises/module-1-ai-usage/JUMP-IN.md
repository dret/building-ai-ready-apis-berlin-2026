# Module 1 — Jump-In Guide

**Arriving mid-workshop? Start here.**

## What This Module Is About

This is a 25-minute analytical exercise. You read a deliberately rough API spec and map the risks it creates for AI agents. No tools or setup needed — just the spec and the worksheet.

## What You Need

| File | What to do |
|------|-----------|
| `book-catalog-raw.openapi.yaml` | Open and read — this is the spec you're analysing |
| `risk-mapping-worksheet.md` | Complete at least Sections 1, 2, and 3 |

## Quickest Path (5 minutes)

Scan the spec and complete just **Section 3: Missing Information** in the worksheet. This is the most impactful section — it shows you what AI agents depend on that is simply absent from most API specs.

## Connection to the Workshop

The problems you find here are exactly what the rest of the workshop teaches you to fix:
- Module 2 fixes ambiguity and missing information (better OpenAPI design)
- Module 3 fixes governance gaps (Overlay)
- Module 5 measures and scores these dimensions (Jentic AI-Readiness)
